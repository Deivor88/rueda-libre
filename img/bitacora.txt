HTML: Es la estructura y el esqueleto de la página web. Se encarga de definir el contenido básico, como los títulos, párrafos, listas de servicios, imágenes y formularios de contacto.

<h1>Rueda Libre</h1>
<ul>
    <li>Alquiler de bicicletas por hora o por día</li>
    <li>Rutas guiadas por la ciudad</li>
</ul>

CSS: Es el diseño, el estilo y la apariencia visual del sitio. Se encarga de darle personalidad a la marca (colores institucionales, tipografías, alineaciones y espacios), asegurando además que la página se vea atractiva y se adapte correctamente a celulares, tabletas y computadoras (diseño responsivo).

body {
    background-color: #0d3b44; /* Fondo azul oscuro corporativo */
    color: #fffff0; /* Texto claro */
    font-family: 'Arial', sans-serif;
}
h1 {
    color: #f4d35e; /* Título en tono amarillo/crema destacado */
    text-align: center;
}
JAVASCRIPT: Es la capa de interactividad y dinamismo. Permite que el sitio web reaccione a las acciones del usuario, como validar un formulario de reserva de bicicletas, abrir un menú desplegable en dispositivos móviles, mostrar un mapa interactivo con las rutas o calcular el costo total de un alquiler en tiempo real.

function calcularCostoAlquiler(horas) {
    const tarifaPorHora = 15000; // en pesos colombianos
    let total = horas * tarifaPorHora;
    return `El costo total por ${horas} horas es de $${total} COP`;
}
